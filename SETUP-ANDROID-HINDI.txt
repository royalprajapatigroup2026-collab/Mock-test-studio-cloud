MOCK TEST STUDIO — GITHUB PAGES + SUPABASE SETUP
==================================================

CURRENT HOSTING ARCHITECTURE
- Frontend: GitHub Pages (static index.html/PWA files from this repository).
- Backend: Supabase project cvs obyzmwzcakbtteqol (project ref: cvs obyzmwzcakbtteqol).
- Database: public.published_mock_tests stores published tests.
- Gemini connection: Supabase Edge Function ai-question-studio.
- Gemini API key: stored in Supabase Vault with the secret name "Gemini Api key".
- Task scheduler: Supabase pg_cron calls the Edge Function worker every minute.
- Long-term studio data: ai_question_tasks, ai_studio_conversations, ai_studio_memories.

NO NETLIFY DEPENDENCY
Netlify is not used by this release. Do not configure a Netlify site, Netlify Functions, Netlify Blobs, or a Netlify environment variable for this architecture.

GITHUB PAGES
1. In the GitHub repository, open Settings → Pages.
2. Configure the publishing source to Deploy from a branch.
3. Select branch main and folder /(root), then save.
4. Keep index.html, manifest.json, service-worker.js, icons/, and .nojekyll in the repository root.
5. New commits to main should be picked up by the GitHub Pages publisher according to its build status.
6. The PWA service worker cache version is bumped when the app shell changes. When testing updates, close the installed PWA fully and reopen it while online.

SUPABASE BACKEND
- Edge Function: ai-question-studio.
- Function endpoint: https://cvsobyzmwzcakbtteqol.supabase.co/functions/v1/ai-question-studio
- Function uses a private server-side admin token and a separate scheduler token.
- Gemini API key is resolved from Supabase Vault. Never put the Gemini key or Supabase service-role/secret key into index.html, GitHub Pages, or any other public file.
- The browser uses only the Supabase publishable/anon client key for reading the published tests feed and calls the Edge Function with the separate AI Studio access token.
- Private task, conversation and memory tables have RLS enabled and no anon/authenticated policies. They are accessed by the Edge Function's server-side credentials.

AI QUESTION STUDIO
- Open the "AI Question Studio" button in the app toolbar.
- Enter the AI Studio access token in the Unlock / Connect field.
- Connection check verifies the Vault Gemini key and attempts a live Gemini request.
- Create a task with a test title, subject, topic, difficulty, number of questions, run time, deadline, instructions and optional source text.
- A task is processed in batches. Questions must contain a question stem, exactly four options, a zero-based correctAnswer index (0–3), and an explanation.
- On completion, the generated test is published to public.published_mock_tests with is_published=true.
- It then appears in the existing Select Subject → Published Online Mock Tests selector.
- AI-generated labour-law questions must still be verified against the relevant Bare Act, amendments and official sources before exam use.

SUPABASE TABLES
- public.published_mock_tests: public published mock-test feed (only published rows are readable to anon/authenticated).
- public.ai_question_tasks: private task queue and generation progress.
- public.ai_studio_conversations: saved Gemini chat history.
- public.ai_studio_memories: persistent context supplied to Gemini on later chats and tasks.

TROUBLESHOOTING
- If the AI Studio button is missing, verify that GitHub Pages is publishing the latest main branch commit and refresh the PWA after closing it fully.
- If Connect reports a token error, use the AI Studio access token configured for this project; do not paste the Gemini API key into the website.
- If Gemini is not detected, confirm the Vault secret name is "Gemini Api key".
- If a task stays scheduled, check that the Supabase cron job ai-studio-task-worker is active.
- If a task fails, inspect its last_error in Task Manager and Supabase Edge Function logs.
- If a generated test does not appear immediately, refresh the Published Online Mock Tests selector after task status becomes completed.

SECURITY
- Never commit Gemini API keys, service-role keys, Supabase secret keys, AI Studio admin tokens, or scheduler tokens to GitHub.
- Do not publish confidential, paid or unreleased question content.
- Treat AI-generated statutory facts as draft material until independently verified.
