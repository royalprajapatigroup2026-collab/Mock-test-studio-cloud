MOCK TEST STUDIO — GITHUB PAGES / SUPABASE AUDIT NOTES
=========================================================

CURRENT ARCHITECTURE
- Static frontend is maintained in the GitHub repository and intended to be published by GitHub Pages from main /(root).
- Supabase provides database, Edge Functions, Vault secrets and scheduled task processing.
- Netlify is not part of the current deployment architecture.

FRONTEND CHECKS
- index.html contains the AI Question Studio toolbar button and modal.
- Frontend calls the Supabase Edge Function ai-question-studio.
- Frontend uses only the Supabase public client key for the published-test read feed and Edge Function request.
- Gemini API key is not embedded in index.html.
- service-worker.js cache version is v10 so an older cached app shell is invalidated.
- .nojekyll is present for static GitHub Pages publishing.
- Main application and AI Question Studio inline JavaScript passed a syntax check after the latest changes.
- A live browser session on the user's GitHub Pages domain has not been independently verified in this audit.

SUPABASE CHECKS
- public.published_mock_tests remains the existing published test table.
- RLS is enabled on the private ai_question_tasks, ai_studio_conversations and ai_studio_memories tables; browser roles have no direct policies for those tables.
- Supabase Edge Function ai-question-studio is ACTIVE.
- Function reads the Gemini key from Supabase Vault secret "Gemini Api key" via a server-side RPC.
- Vault lookup returned a non-null key.
- The health endpoint returned geminiConfigured=true and model gemini-3.8-flash.
- Cron job ai-studio-task-worker is registered with schedule * * * * *.
- The cron worker reached the Edge Function and returned HTTP 200 during the no-task check.
- A full end-to-end Gemini question generation and automatic publication test has not yet been completed.

IMPORTANT LIMITATIONS
- GitHub Pages site publishing source and final live URL must be checked in the repository owner's Settings → Pages. Repository file commits alone do not prove a Pages deployment has completed.
- The current task worker processes one batch of up to 10 questions per minute.
- Generated questions are automatically published once the task is complete and the shape checks pass. AI content still requires human verification for statutory accuracy.
- Direct PDF upload is not yet implemented in the current AI Question Studio UI; source text can be pasted into the source-material field.

SECURITY
- Do not expose Gemini API key, Supabase service-role/secret key, AI Studio admin token or scheduler token in browser code or GitHub.
- The private task and memory tables must remain protected by RLS.
- Do not publish confidential question sets.
